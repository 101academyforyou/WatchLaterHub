WatchLaterHub 隱私權政策

最後更新：2026 年 10 月 9 日

WatchLaterHub（以下稱「本擴充功能」）是一個 Chrome 新分頁擴充功能。本政策說明本擴充功能會存取哪些資料、如何使用，以及不會做的事。

一、本擴充功能存取的資料

資料用途存放位置
Google 帳號名稱、Email、大頭貼在畫面上顯示目前登入的帳號只存在你的瀏覽器（chrome.storage）
Google OAuth 存取權杖呼叫 YouTube Data API只存在你的瀏覽器
YouTube 播放清單（youtube.readonly）在新分頁隨機顯示一部收藏影片只存在你的瀏覽器
YouTube「稍後觀看」清單（只在你勾選時）YouTube API 不提供這個清單，所以本擴充功能使用你在這個瀏覽器已登入的 YouTube 工作階段，讀取你自己在 youtube.com 上的「稍後觀看」頁面；為了讀取超過 100 部的清單，會讀取 youtube.com 的登入 cookie（SAPISID）來產生 YouTube 要求的驗證標頭清單只存在你的瀏覽器；cookie 不會被儲存，也只會送回 youtube.com
你手動加入的影片、TODO 待辦、筆記與附件（圖片、PDF 等檔案）、計時器、設定提供收藏、待辦、筆記、提醒、計時等功能只存在你的瀏覽器
Chrome 書籤顯示、新增、編輯、排序書籤由 Chrome 管理，本擴充功能不另外保存
Chrome 瀏覽紀錄（最近的網址與標題）在「最近」面板列出近期瀏覽的網頁只存在你的瀏覽器
位置（只在你按「使用目前位置」時）查詢當地天氣只存在你的瀏覽器
目前分頁的網址（只在你按瀏覽器工具列的 WatchLaterHub 圖示時）判斷目前是不是新分頁，以便切換 WatchLaterHub 與 Chrome 原本的新分頁不儲存

二、資料傳送到哪裡

本擴充功能不會把你的資料傳給開發者，也沒有接收你個人資料的伺服器。只有在提供功能時，才會直接從你的瀏覽器連到下列服務：

  • Google（YouTube Data API、Google OAuth、youtube.com）：登入，並以唯讀權限（youtube.readonly）讀取你的播放清單與「稍後觀看」。本擴充功能不會修改你的 YouTube 帳號內容。
  • Open-Meteo、BigDataCloud、OpenStreetMap Nominatim：查詢天氣與地名。只會送出經緯度或你輸入的城市名稱，不包含任何身分資訊。
  • YouTube 縮圖、Google 網站圖示服務：顯示影片縮圖與網站圖示。
  • 贊助內容設定檔（GitHub Pages）：見下方「三、贊助內容（廣告）」。

三、贊助內容（廣告）

  • 新分頁左側可能顯示一則小型贊助內容（一張圖片加一行文字），並清楚標示「贊助」。內容由開發者自行挑選，所有使用者看到的都一樣，不是依你的資料投放的個人化廣告。
  • 為了即時更新內容，本擴充功能最多每 10 分鐘向 GitHub Pages（101academyforyou.github.io，或其自訂網域 onepointzeroone.org）下載一次公開的設定檔 ads.json。這個請求不包含任何你的資料；但就像瀏覽任何網站一樣，GitHub 與圖片所在的主機會看到你的 IP 位址與請求時間。本擴充功能不使用 cookie、追蹤碼或分析工具，也不記錄曝光或點擊。
  • 點擊贊助內容會在新分頁開啟該網站，之後的資料處理依該網站的隱私權政策。
  • 你可以隨時按贊助內容右上角的 ✕ 隱藏；要再顯示，在「收藏」視窗底部勾選「顯示贊助內容」。隱藏後本擴充功能就不再下載設定檔。

四、我們不會做的事

  • 不出售、不出租、不轉讓你的資料給任何第三方
  • 不依你的資料投放廣告，也不把資料用於信用評估或與本擴充功能用途無關的目的
  • 不追蹤你的瀏覽行為、不做分析統計
  • 不存取你的 Gmail 或其他 Google 服務資料（只使用 YouTube 唯讀權限）

本擴充功能使用 Google API 取得的資料，遵守 Google API 服務使用者資料政策，包括「有限使用」（Limited Use）規範。

五、刪除資料與撤銷授權

  • 在「收藏」視窗按「登出」，會撤銷 Google 授權並刪除權杖
  • 移除本擴充功能，會刪除它存在瀏覽器裡的所有資料
  • 你也可以隨時到 Google 帳戶權限頁面 撤銷授權

English summary

  • Your data stays in your browser. Saved videos, to-dos, notes and attachments, settings, the YouTube token and account name are stored only with chrome.storage. Nothing is sent to the developer, and there is no server that receives your personal data.
  • Google / YouTube: read-only access (youtube.readonly) to load your playlists. For your Watch later list (not offered by the YouTube API), the extension reads your own Watch later page on youtube.com using the YouTube sign-in already in this browser, and reads the youtube.com SAPISID cookie only to build the authorization header youtube.com requires for loading more than 100 videos. The cookie is never stored and is sent only back to youtube.com.
  • Bookmarks, history, location: used only to show your bookmarks, your recently visited pages and local weather (location only when you click “Use current location”, sent to Open-Meteo, BigDataCloud and OpenStreetMap).
  • Toolbar button: when you click it, the extension reads the current tab's URL only to check whether it is a new tab page. The URL is not stored.
  • Sponsored content: the new tab may show one small item labeled “Sponsored”. It is the same for everyone and is not personalized. To keep it up to date, the extension downloads a public settings file (ads.json) from GitHub Pages at most every 10 minutes; the request contains none of your data, though GitHub and the image host can see your IP address, as with any web request. No cookies, tracking or analytics are used, and impressions and clicks are not recorded. Hide it any time with ✕, and the file is no longer downloaded.
  • We never sell or share your data, never use it for advertising or credit decisions, and follow the Google API Services User Data Policy, including the Limited Use requirements.
