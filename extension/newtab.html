                    手動加入

                      啟用 Google 登入（只需設定一次）

                      Google 規定每個「用 Google 登入」的應用程式都要有一組 OAuth Client ID。照下面 4 步做完，之後按一下就能選帳號登入。

                      1. 啟用 YouTube API 開啟 → 按「啟用」
                        第一次使用會先要你建立專案，名稱隨意。
                      2. 設定 OAuth 同意畫面 開啟 → 按「開始」
                        選「外部」，填應用程式名稱與 email。在「目標對象」把你自己的 Google 帳號加入測試使用者。
                      3. 建立 OAuth 用戶端 開啟

                      4. 貼上用戶端 ID
